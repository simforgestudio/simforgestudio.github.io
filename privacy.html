Privacy Policy

Effective date: 16 October 2026

This policy explains how SimForge Studio ("we") handles information in connection with this website and with SimForge Uploader, our internal application that uses YouTube API Services.

Who uses SimForge Uploader

SimForge Uploader is used only by SimForge Studio to manage the YouTube channels that the studio owns. It is not offered to the public, and we do not ask any other person to sign in to it.

YouTube API Services

SimForge Uploader uses YouTube API Services. By using it, the account holder agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the application accesses

With the account holder's permission, granted through Google's OAuth consent screen, the application requests these scopes:

  • youtube.upload: to upload videos produced by the studio to its own channels.
  • youtube.readonly: to read the channel's name and identifier, so that the tool confirms it is uploading to the correct channel, and to list the channel's own videos.
  • yt-analytics.readonly: to read aggregate performance statistics (such as views and watch time) for the studio's own channels.

How the data is used

The data is used only to upload the studio's videos and to evaluate how those videos perform. We do not use it for advertising and we do not sell, rent or share it with third parties. We do not use it to build profiles of YouTube viewers. Our use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and security

OAuth access and refresh tokens, and any statistics the tool reads, are stored only on the studio's own computer. They are excluded from source control and are not uploaded to any server operated by us. We do not run a backend service that receives this data.

Retention and deletion

Tokens are kept only while the studio uses the tool and are deleted when access is no longer needed. Access can be revoked at any time from Google Account permissions (also reachable at security.google.com/settings/security/permissions). Once access is revoked, the tool can no longer read or upload anything, and the stored tokens stop working. To request deletion of any stored data, email us at the address below; we will delete it within 30 days.

This website

This website does not use cookies, analytics or tracking scripts, and it has no forms. Its fonts and scripts are served from this site itself, so visiting it makes no requests to third parties. The small animations on the homepage run entirely in your browser and send nothing anywhere. The site is hosted on GitHub Pages; GitHub may log technical information such as IP addresses to operate and secure its service, as described in the GitHub Privacy Statement.

Children

SimForge Uploader is not directed at children and does not knowingly collect information from children.

Changes

If this policy changes, we will update this page and its effective date.
