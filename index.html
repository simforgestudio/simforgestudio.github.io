The pipeline

From an equation to a finished short.

Every format is a small program. Change a parameter and you get a new video; keep the seed and you get the same one, frame for frame.

  1. Script

    An idea becomes a set of parameters: what moves, what collides, what the viewer should wonder about.

  2. Simulate

    Physics engines and numerical solvers do the acting. Nothing is animated by hand.

  3. Render

    Blender and Python turn the result into frames; FFmpeg adds sound and assembles the final cut.

  4. Publish

    A quality gate checks every video before it goes out to the right channel.

arena_race.py (simplified)
from simforge import Scene, Orb, render

scene = Scene(fps=60, seconds=58, size=(1080, 1920))

for color in ["ember", "magenta", "cyan", "lime"]:
    scene.add(Orb(color=color, radius=0.04, bounce=0.98))

scene.arena(shape="ring", shrink_per_hit=0.002)
scene.simulate(seed=2026)   # same seed, same race

render(scene, engine="cycles", denoise="gpu")

SimForge Uploader

SimForge Uploader is an internal tool used only by SimForge Studio. It connects to the YouTube Data API so that the studio can upload the videos it produces to its own channels and read basic performance statistics for them.

It is not offered to the public and does not access anyone else's account. Data handling is described in our Privacy Policy.
